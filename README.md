# Cleanly — productafbeeldingen Kaufland.de

Tijdelijke publieke opslag zodat Kaufland de afbeeldingen één keer kan ophalen bij het
importeren van de productdata. Kaufland zet ze daarna op hun eigen CDN.

Deze repo kan weg zodra alle listings verwerkt zijn.

Eén map per SKU, bestandsnaam `{SKU}_{volgnummer}.jpg`, allemaal 2000×2000 JPEG.
